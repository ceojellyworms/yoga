# Flow Studio: проектный контекст

## Идея продукта

Flow Studio — multi-tenant платформа для небольших йога-клубов и танцевальных студий. Суперадминистратор создаёт отдельную публичную страницу и учётную запись для бизнеса. Администратор бизнеса сам редактирует содержание сайта, расписание, тренеров, заявки и настройки; суперадминистратор сохраняет технический доступ к каждому проекту.

У проекта есть три варианта направлений: `yoga`, `dance` и `both`. Публичный сайт показывает только выбранные направления.

## Текущая архитектура

- Статические HTML/CSS/Vanilla JS файлы развёртываются на Vercel.
- `studio.html` — клиентская страница; `app.js` загружает публичные данные по slug из адреса.
- `admin.html` и `admin.js` — вход для администратора клуба и интерфейс суперадминистратора.
- `index.html` — отдельная форма входа; `login.js` обслуживает этот маршрут.
- Supabase хранит студии, тренеров, занятия, заявки, профили и связь администраторов с проектами. Изоляция данных обеспечивается RLS.
- Edge Functions: `create-project`, `manage-project`, `login-project-admin`, `send-tg-alert`, `check-tg-start`.
- Миграции БД находятся в `supabase/migrations`; фотографии тренеров хранятся в Storage.
- Модели 3D в `assets`: статуя Будды для первого экрана, модель йоги и танцовщицы для карточек, диорама йога-пространства для фона и секции атмосферы.
- `vendor/liquid-glass` содержит локальный код Liquid Glass JS с лицензией MIT.

## Важные настройки

- Публичная страница открывается по `/flow-studio` либо по slug студии.
- Админка открывается по `/admin`.
- Для Supabase нужны значения из `config.js` и применённые миграции; Edge Functions развёртываются отдельно.
- Никогда не записывать значения ключей из `config.js` в этот документ или в публичные логи.

## Дизайн

- Основной шрифт — Muli (текущее имя семейства в Google Fonts — Mulish); контрастный — Crimson Text.
- Направление: спокойная ботаническая эстетика с мятно-зелёной гаммой, 3D-объектами, адаптивной типографикой и стеклянными поверхностями.
- Основная диорама меняет ориентацию по прогрессу прокрутки. Учитывать `prefers-reduced-motion`.
