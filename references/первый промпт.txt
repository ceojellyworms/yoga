# РОЛЬ И КОНТЕКСТ
Ты — Senior Full-Stack Developer с 10-летним опытом и UI/UX дизайнер уровня Awwwards. 
Твоя задача — написать Production-Ready PWA (Progressive Web App) под названием "Flow Studio" для студии йоги и танцев.
Целевая аудитория: девушки 16-35 лет. Дизайн должен быть максимально эстетичным, "инстаграмным", легким и современным.

# ТЕХНИЧЕСКИЙ СТЕК
- Frontend: Чистый HTML5, CSS3 (Tailwind CSS через CDN), Vanilla JavaScript (ES6+). НИКАКИХ React/Vue.
- 3D-графика: Web Component `<model-viewer>` (Google) для интерактивных 3D-моделей в карточках.
- Backend: Supabase (PostgreSQL, Auth, Edge Functions на Deno).
- Хостинг: Vercel (статика).
- Дизайн-система:
  - Основные цвета: Нежно-мятный (#E0F7FA), Аквамариновый/Циан (#4DD0E1), Белый (#FFFFFF).
  - Стиль: Glassmorphism (полупрозрачные карточки с backdrop-blur), мягкие тени, скругленные углы (rounded-2xl).
  - Шрифты: 'Montserrat' или 'Inter' (подключить через Google Fonts).
  - Анимации: Плавные fade-in при скролле, hover-эффекты на кнопках.

# АРХИТЕКТУРА БАЗЫ ДАННЫХ (Supabase SQL)
Напиши SQL-скрипт для создания таблиц. Обязательно настрой RLS (Row Level Security).

1. `studios`: 
   - id (uuid, primary key)
   - user_id (uuid, ссылка на auth.users)
   - name (text)
   - tg_bot_token (text, nullable)
   - tg_chat_id (text, nullable)
   - trial_enabled (boolean, default true)
   - show_prices (boolean, default true)
   - created_at (timestamp)

2. `trainers`:
   - id (uuid, primary key)
   - studio_id (uuid, references studios)
   - name (text)
   - photo_url (text)
   - bio (text)

3. `classes`:
   - id (uuid, primary key)
   - studio_id (uuid, references studios)
   - trainer_id (uuid, references trainers, nullable)
   - title (text) // Например: "Хатха-йога для начинающих"
   - day_of_week (int) // 1-7
   - time_start (time)
   - duration_minutes (int)
   - max_capacity (int)
   - current_bookings (int, default 0)
   - model_url (text) // Ссылка на .glb файл для 3D
   - color_theme (text) // Для красоты карточки (например, 'mint' или 'cyan')

4. `bookings`:
   - id (uuid, primary key)
   - class_id (uuid, references classes)
   - client_name (text)
   - client_phone (text)
   - status (text, default 'pending')
   - created_at (timestamp)

# ПОЛИТИКИ БЕЗОПАСНОСТИ (RLS)
- Анонимные пользователи (клиенты) могут делать SELECT из `classes`, `trainers`, `studios` (только публичные поля).
- Анонимные пользователи могут делать INSERT в `bookings`.
- Авторизованный пользователь (владелец студии) может делать всё только со своими записями (где studio_id привязан к его user_id).

# ЛОГИКА TELEGRAM (Supabase Edge Function)
Напиши Edge Function на TypeScript (Deno) с названием `send-tg-alert`.
- **Триггер:** Вызывается из фронтенда (или через Webhook на INSERT в таблице bookings).
- **Логика:**
  1. Получает `class_id` и данные клиента.
  2. Делает запрос в БД, чтобы найти `tg_bot_token` и `tg_chat_id` студии.
  3. Если токен есть, отправляет POST-запрос в `https://api.telegram.org/bot<TOKEN>/sendMessage`.
  4. Текст сообщения: "🌸 Новая заявка в Flow Studio!\nЗанятие: {title}\nВремя: {time}\nКлиент: {name}\nТелефон: {phone}".
  5. Возвращает 200 OK.

# БЛОК ИНТЕГРАЦИИ 3D-АССЕТОВ (Добавить в секцию "Направления" или Hero)

У тебя есть два готовых локальных 3D-файла в формате .glb, которые нужно красиво вписать в дизайн сайта. Используй тег `<model-viewer>`.

## Ассет 1: Статуя Будды
- **Путь к файлу:** `assets/yoga_-_buddha.glb`
- **Описание:** Детализированная статуя Будды в позе лотоса, бронзовый/золотой оттенок, выглядит умиротворяюще.
- **Где использовать:** В карточке направления "Йога" или в секции Hero.
- **Настройки `<model-viewer>`:** 
  - `auto-rotate` (медленное вращение), `camera-controls`.
  - Задай `shadow-intensity="1"` и `shadow-softness="0.8"`, чтобы под статуей была мягкая падающая тень, и она не висела в воздухе на белом фоне.
  - `exposure="1.2"`, чтобы бронза красиво блестела на светлом фоне.

## Ассет 2: 3D-Диорама (Йога-Барн)
- **Путь к файлу:** `assets/virtual_fantasy_yoga_barn.glb`
- **Описание:** Широкая 3D-сцена (диорама) с деревом бонсай, кругом из деревянных досок, темными камнями и землей. Контрастирует со светлым дизайном сайта.
- **Где использовать:** Как большая фоновая 3D-модель на всю ширину экрана в секции "О студии" или "Атмосфера", либо как фича-карточка.
- **Настройки `<model-viewer>`:**
  - Так как модель широкая (landscape), задай контейнеру CSS свойство `aspect-ratio: 16/9` и `width: 100%`.
  - `auto-rotate` и `disable-zoom` (чтобы на мобилках страница не застревала при попытке скролла).
  - `camera-orbit="0deg 75deg 105%"` (чтобы камера смотрела на сцену сверху под углом).
  - Так как сцена темная, помести её в контейнер с легким градиентным фоном (например, от белого к светло-мятному) или добавь CSS-тень контейнеру, чтобы она контрастировала с белым сайтом.

## Требования к UI вокруг 3D:
- Не ставь жесткие рамки вокруг моделей. Сделай им `border-radius: 24px`.
- Если модель темная (как диорама), добавь вокруг неё легкую бело-мятную подсветку (box-shadow с цветом #4DD0E1).
